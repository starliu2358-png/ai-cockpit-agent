# Mock Vehicle Owner Manual

## TPMS / 胎压报警
胎压监测系统（TPMS）用于监测轮胎压力。当胎压报警灯持续点亮时，应在安全地点停车并检查各轮胎压力。若轮胎明显亏气、破损或报警持续存在，应减少高速行驶并联系维修服务。不要仅通过复位报警来替代轮胎检查。

## ABS / 防抱死制动系统
ABS 指示灯在车辆上电自检时可能短暂点亮。如果行驶中持续点亮，表示防抱死制动功能可能存在异常。基础制动通常仍可工作，但紧急制动时车轮防抱死能力可能受影响，应谨慎驾驶并尽快检查。

## 空调系统
自动空调可设置目标温度。本演示系统允许设置 16°C 至 30°C。为了减少频繁调节，可先调整 1°C 至 2°C，再观察体感。

## 座椅加热
主驾座椅加热提供 0 至 3 档，其中 0 为关闭、1 为低、2 为中、3 为高。长时间使用高档位可能造成不适，建议根据体感适当降低档位。

## 车门安全
车辆行驶过程中不应打开车门。本演示 Agent 在车速高于 0.5 km/h 时会拒绝执行左前门开启请求。

## 车窗控制
主驾车窗可按百分比设置开度：0% 表示完全关闭，100% 表示完全打开。高速行驶时大开度车窗可能增加风噪和能耗。
